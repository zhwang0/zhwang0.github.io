# CarbonGlobe homepage teaser

The teaser and `../img/carbonglobe-poster.jpg` are derived from the CarbonGlobe
project's own film, retrieved on 2026-10-27:
https://zhwang0.github.io/carbon-globe-website/assets/film/carbonglobe-film.mp4

- Teaser: source 00:26–00:38, 960 × 540, 24 fps, silent H.264/yuv420p,
  fast-start MP4, 0.3-second fades at the loop boundaries; approximately 1 MB.
- Poster: source frame at 00:31.5, 960 × 540; approximately 43 KB.
- The homepage requests the teaser only while visible and motion is allowed.
  The full film remains hosted on the project site and loads only on click.
